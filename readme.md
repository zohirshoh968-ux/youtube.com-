## 📖 Loyiha haqida

**VideoTube** — bu YouTube platformasidan ilhomlanib yaratilgan video xosting sayti. Loyiha foydalanuvchilarga tanish, qulay va chiroyli interfeysni taqdim etadi: video ko'rish, qidirish, Shorts, obunalar, tarix va yoqqan videolarni boshqarish hamda kontent yaratuvchilar uchun Studiya bo'limi.

🔗 **Sayt manzili:** [https://youtube-lu.netlify.app/](https://youtube-lu.netlify.app/)

## 🌍 Deploy (Netlify)

Sayt **Netlify** orqali joylashtirilgan. O'zingiz deploy qilish uchun:

1. [Netlify](https://www.netlify.com/) hisobingizga kiring
2. **Add new site → Import an existing project** ni tanlang
3. GitHub repozitoriyangizni ulang
4. **Deploy site** tugmasini bosing

Har bir `git push` dan keyin sayt avtomatik yangilanadi ✅
